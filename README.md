# Mi Web!!!!!!

Página web estática y sencilla creada con HTML, CSS y JavaScript. Incluye una interfaz minimalista, un botón interactivo de inspiración y un reloj analógico en tiempo real.

## Funcionalidades

- Diseño responsive para escritorio y dispositivos móviles.
- Botón **Dame una chispa** con mensajes de inspiración aleatorios y contador de activaciones.
- Reloj analógico fijo en la esquina inferior derecha.
- Animaciones suaves de entrada.
- Tipografías y estilos cargados desde Google Fonts.

## Estructura del proyecto

```text
mi web/
├── index.html   # Estructura y contenido de la página
├── styles.css   # Estilos, diseño responsive y animaciones
├── script.js    # Interacciones y funcionamiento del reloj
└── README.md    # Documentación del proyecto
```

## Cómo ejecutar el proyecto

No requiere instalación ni dependencias.

1. Abre el archivo `index.html` directamente en un navegador.
2. Pulsa **Dame una chispa** para probar la interacción.
3. El reloj mostrará automáticamente la hora local del dispositivo.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para visualizar los cambios en tiempo real.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts

## Programa de consola de tareas

El archivo `tareas.py` contiene una lista de tareas que permite anadir tareas,
listarlas, marcarlas como completadas y salir del programa.

Para ejecutarlo desde la carpeta del proyecto:

```bash
python tareas.py
```

Si en Windows tienes instalado el lanzador de Python, tambien puedes usar:

```bash
py tareas.py
```

Elige una opcion del menu y sigue las indicaciones. Las tareas se mantienen en
memoria mientras el programa esta abierto.

## Compatibilidad

Compatible con navegadores modernos que soporten CSS Grid, CSS Custom Properties y JavaScript ES6.
